# 제작 세션 교훈 (증상 → 원인 → 수정)

죽림 무협 시리즈(씬 0~5, Seedance 2.5, 21:9, 2026-10) 제작 중 사용자 피드백으로 확인한 것들. 새 피드백이 오면 아래에 한 줄씩 추가한다.

| # | 증상 | 원인 | 수정 문장/방법 |
|---|---|---|---|
| 1 | 12fps로 바꿨더니 전체가 뚝뚝 끊김 | 카메라 무빙까지 on twos로 지시 | "Characters on twos at 12fps; camera, backgrounds, FX on ones at 24fps." |
| 2 | 프롬프트 뒷부분(MOTION STYLE)이 안 먹음 | 6,000~7,000자, 한도 초과 | 4,000자 이내. 중복 블록 제거 |
| 3 | 샷 사이가 녹아서 이어짐 | MULTI-SHOT만 쓰고 컷 표시 없음 | `N.0s HARD CUT` + "Cuts only at the marked points" |
| 4 | 첫 프레임부터 어색 | @image1을 첫 프레임으로 지정했는데 첫 샷 자세가 다름 | 레퍼런스는 캐릭터용으로만 사용 |
| 5 | 날아오는 작은 표창이 어설픔 | 작은 투사체 다수는 읽히지 않음 | 공격자를 보여 준다(암살자 2명) |
| 6 | 카메라가 정적 | 고정·수평 지시 위주 | 다이브·휘감기·나란히 트래킹 + km/h |
| 7 | 구도가 전부 정면·평면적 | 앵글·기울기 미지정 | 매 샷 앵글 변경 + horizon tilt + 전경 레이어 |
| 8 | 속옷·바지가 덧입혀짐 | 필터를 피하려고 내가 임의로 의상 추가 | 사용자 설정을 지키고, 가림은 사물·머리카락·앵글로 |
| 9 | 몸이 새까맣게 나옴 | "solid black ink silhouette", "strong black silhouettes" | "bold ink outlines", "soft ink-wash shade" |
| 10 | 허벅지 조르기가 목마 탄 것처럼 보임 | 상태만 적음, MOTION STYLE의 restrained | 4자 잠금 + 상체 비틀기 + "three hard pulses" + 상대 반응 + 과장 예외 |
| 11 | 화살이 멈춰 있음 | 어깨너머 망원에서 깊이축으로 멀어짐 | 측면에서 화면을 가로지르게, "moving the entire time" |
| 12 | 화살이 등 뒤에서 와서 어색 | 대응 연출 없음 | 소리에 눈 → 회전 회피 → 카메라가 회전을 따라감 |
| 13 | 4명이 쓰러져 있는데 1명은 안 쓰러뜨림 | 안무 회계 누락 | 적 한 명 한 명의 결말을 적는다 |
| 14 | 연속 추격인데 씬마다 칼을 칼집에 넣음 | 씬을 독립적으로 씀 | 씬 간 상태표: 씬 0에서 뽑고 칼집을 버림 → 끝까지 맨 칼 |
| 15 | 놓친 칼이 컷마다 다시 손에 | 컷마다 레퍼런스 재참조, "swordswoman" 이름표, 위치 미추적 | 이름표를 heroine으로, 매 샷 빈손 명시, 칼 위치 추적, LOCKS. 최후 수단은 무기 없는 레퍼런스 |
| 16 | 몸이 노출되는 장면 | 단어로 노출을 지시하면 거부됨 | 날아가는 옷·파편·머리카락·무릎·옅은 그늘로 가림 |
| 17 | 그림체 차이(셀 채색 레퍼런스 + 먹선 씬) | 레퍼런스가 스타일을 끌고 감 | 씬 STYLE에 선·채색을 구체적으로 적어 덮기 |
| 18 | 새로 짠 30초 프롬프트가 "개판"으로 나옴 | 코다 원문 대신 내가 블록식, 12fps 2단 지시, 4,000자 압축, 낯선 기믹(끈 달린 칼 던지기)을 섞어 새로 씀 | 새 레퍼런스로 처음 생성할 때는 **검증된 코다 원문을 최소 수정(레퍼런스·무기 이름만 교체)**으로 먼저 돌린다. 자작 설계는 그다음에 1변수씩 |
