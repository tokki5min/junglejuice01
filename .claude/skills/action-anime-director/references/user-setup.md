# 사용자 작업 환경 메모

## 생성 결과 보관 위치 (사용자 PC)
- 루트 폴더: `F:\DOLA_영상_정리본\계정별\`
- 계정별로 하위 폴더가 있다. 예: `matcha01(갈색)\30초기술\353_joined.mp4`
- 같은 실험을 2~3개 계정에서 나눠 돌린 경우가 많다. 검토할 때는 계정 폴더를 모두 확인한다.
- 알려진 계정 폴더: `matcha01(갈색)`, `jundorius2(파란색, …)`
- 예: Crimson Ribbon 실험은 3개 테이크로 나뉘어 있다. t1·t2는 `jundorius2(파란색…)`, t3은 `matcha01(갈색)\30초기술\353_joined.mp4`에 있다.
- 파일 이름의 `_joined`는 15초씩 나눠 생성한 두 클립을 이어 붙인 결과다.
- 이 경로는 사용자 PC에 있다. 클라우드 세션에서는 직접 열 수 없다. 데스크톱 앱이나 `claude remote-control` 세션에서 열거나, 사용자가 파일을 올려 줘야 한다.

## 생성 도구: Dola AI
- 생성 이름 예: `ui261009-2007_SCENE_—_Crimson_Ribbon_o_t3`
- 생성 메시지에 "follow the tool plan exactly", "고속" 같은 문구가 붙는다. Dola가 자체 도구 계획에 따라 레퍼런스를 첨부하고 호출을 나누며, 고속 모드로 돌리는 경우가 있다.
- **한 번에 최대 15초만 생성한다.** 30초 프롬프트는 도구가 자동으로 2회(0~15초, 15~30초)로 나눈다. 두 번째 호출은 "continuing exactly from the match-cut frame"처럼 앞 클립의 마지막 프레임에서 이어 생성한다.
- 결과적으로 **15초 지점이 생성 이음매**가 된다. 이음매에 어려운 동작을 두지 않는다(§ session-lessons 19).
