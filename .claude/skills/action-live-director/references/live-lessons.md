# 실사 액션 교훈 (증상 → 원인 → 수정)

실사 제작 피드백이 들어오면 아래 표에 한 줄씩 추가한다. 처음 항목은 애니 제작 세션에서 얻은 교훈 가운데 실사에도 그대로 통하는 것들이다.

| # | 증상 | 원인 | 수정 |
|---|---|---|---|
| 1 | 프롬프트 뒷부분 지시가 무시됨 | 4,000자 초과 | 배경 묘사를 먼저 줄인다 |
| 2 | 샷끼리 녹아 이어짐 | 컷 표시 없음 | `HARD CUT` 또는 `MATCH CUT ON ACTION`을 시각과 함께 표시 |
| 3 | 화살·총알이 멈춰 보임 | 피사체가 카메라 축 방향으로만 움직임 | 측면에서 화면을 가로지르게 + `moving the entire time` |
| 4 | 구도가 평면적 | 앵글 미지정 | 샷마다 앵글 변경, 더치 틸트, 전경 레이어 |
| 5 | 잃은 무기가 다시 손에 생김 | 컷마다 레퍼런스를 다시 참조함 | 샷마다 빈손 명시 + 무기 위치 추적 + 무기 없는 레퍼런스 |
| 6 | 의상이 덧입혀짐 | 프롬프트에 임의로 의상 추가 | 사용자 설정을 지키고, 가림은 사물·앵글로 |
| 7 | 잡기·조르기에 힘이 없음 | 상태만 적음 | 잠그는 방법 + 힘을 거는 리듬 + 상대 얼굴 반응 |
| 8 | 씬 사이에 무기·옷 상태가 리셋됨 | 씬을 따로따로 씀 | 씬 간 상태표를 만들어 LOCKS에 반영 |
